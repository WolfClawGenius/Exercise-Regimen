# Exercise-Regimen

A static fitness and nutrition portal for adults 50 and older. The site combines a low-impact metabolic workout with a practical meal plan designed for compact living and limited refrigerator space.

## What the site includes

- **Low-impact metabolic circuit:** Four joint-friendly movements performed as timed intervals:
	- Chair sit-to-stands
	- Low-impact step jacks
	- Incline wall or counter push-ups
	- Standing march with core rotation
- **Interval workout timer:** Start 45-second work intervals, 30-second rest intervals, or reset the timer from the Workout page.
- **Exercise library:** Movement demonstrations, setup instructions, technique guidance, and safety checkpoints.
- **Circuit guidelines:** Recommended frequency, rounds, rest periods, progression, and workout objectives.
- **15-day meal plan:** Two phases that combine fresh ingredients, shelf-stable foods, canned proteins, grains, vegetables, and high-fiber meals.
- **Mini-fridge grocery list:** Shopping recommendations and storage strategies for a 3.2 cu. ft. refrigerator.
- **Meal preparation guide:** Microwave oatmeal instructions and space-saving food-storage techniques.

## Getting started

This project uses plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation links to move between the workout, exercise, meal, grocery, and preparation pages.

The pages share the styles in [`style.css`](style.css). The interval timer is implemented directly in [`circuit.html`](circuit.html).

## Important note

This site provides general fitness and meal-planning information. It is not medical advice. Consult a qualified healthcare professional before beginning a new exercise or nutrition program, especially when managing an existing health condition.
